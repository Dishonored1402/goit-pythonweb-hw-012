# Contacts REST API (HW-012)

**Це мій проект на FastAPI для управління списком контактів. У цій версії я зосередився на безпеці, контейнеризації та автоматичному документуванні коду.**

### Що додано в цій версії:
*   **Авторизація та безпека:** Реалізовано реєстрацію та вхід за допомогою JWT-токенів (Access та Refresh). Кожен користувач має доступ лише до своїх даних.
*   **Аватари:** Інтеграція з **Cloudinary** дозволяє користувачам завантажувати та оновлювати свої фото профілю.
*   **Валідація Email:** Додано сервіс для надсилання листів підтвердження реєстрації.
*   **Документація (Sphinx):** Окрім стандартного Swagger, додано професійну технічну документацію, згенеровану через Sphinx.
*   **Docker Compose:** Весь проект (додаток, база даних PostgreSQL та Redis) запускається однією командою.

**2. Запуск через Docker:**
