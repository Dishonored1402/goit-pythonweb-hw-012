**Це мій проект на FastAPI для управління списком контактів. В цій частині я додав систему реєстрації користувачів, захист даних за допомогою JWT-токенів та можливість завантажувати аватарки**

**Що я додав у цій версії:**
**Авторизація:** Тепер кожен користувач бачить тільки свої контакти. Паролі зберігаються в зашифрованому вигляді

**Аватари:** Додав інтеграцію з Cloudinary. Можна завантажити свою картинку профілю

**Обмеження (Rate Limit):** На маршрут /me встановлено ліміт запитів, щоб не перевантажувати сервер

**CORS:** Налаштував, щоб API можна було підключити до веб-сторінок

**Docker:** Весь проект тепер запускається однією командою через Docker Compose

**Як запустити проект**
Варіант через Docker (найшвидший):

Створіть файл .env і скопіюйте туди дані з прикладу

**Виконайте команду в терміналі:**

    ```bash
    docker-compose up --build
    ```

**Локальний запуск (якщо немає Докера):**
    
**Встановіть залежності:** pip install -r requirements.txt

**Запустіть сервер:** uvicorn main:app --reload

**Як користуватися**
Документація доступна тут: http://localhost:8000/docs

**Основні запити:**

**POST /api/auth/signup** — Реєстрація нового акаунта.

**POST /api/auth/login** — Вхід. Після цього натисніть кнопку Authorize зверху в Swagger і введіть свій логін/пароль.

**GET /api/auth/me** — Переглянути свій профіль (діє ліміт запитів).

**PATCH /api/auth/avatar** — Завантажити нову фотографію для профілю.

**GET /api/contacts/birthdays** — Список іменинників на найближчий тиждень.

**Що треба додати в .env**
**Для роботи обов'язково вкажіть свої ключі:**

SECRET_KEY — будь-який довгий набір символів.

CLOUDINARY_NAME, CLOUDINARY_API_KEY, CLOUDINARY_API_SECRET — дані з вашого кабінету Cloudinary.
